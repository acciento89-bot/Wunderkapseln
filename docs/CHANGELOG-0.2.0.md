# Alpha 0.2.0

## Added
- Twelve world-specific architectural silhouettes and themed backgrounds.
- Five cumulative restoration milestones at 8, 16, 24, 32 and 40 unique wins.
- Localized milestone tracking and a first-crossing celebration; replay does not retrigger it.
- Five original synthesized sound effects for matches, chains, Wonder Moves, wins and losses; native source and browser adapters, mute and compatible saved preference.
- Full 480-level deterministic stress audit and separate browser polish checks.

## Corrected
- Stale input could alter a game after leaving the play screen.
- Repeated initialization could replace an already-started attempt.
- Backgrounding a terminal animation or dismissing its result could leave a finished board onscreen without useful navigation.
- Android/back navigation now returns from victory/loss to level selection and from abandonment confirmation to pause.
- System reduced motion no longer overwrites the player's saved preference.
- Broken native star glyphs replaced; result text line height corrected.
- Native dependency declarations aligned to the checked official SDK-55 manifest.

## Unchanged boundaries
No real purchases, rewarded ads, signing, native builds, store releases or GitHub source upload. No reset of existing progress; canonical launcher/splash artwork unchanged.
