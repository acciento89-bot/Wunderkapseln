# Changelog 0.4.0

Neun neue deterministische Sounds: rocket, bomb, prism, mega, wind, tide, bloom, charge und restoration. Fuenf bestehende Sounds unveraendert.

Effekte starten an der Burst-Animation. Sieg/Niederlage und neuer Welt-Meilenstein folgen getrennt. Reduzierte Bewegung komprimiert Klangfeedback ohne Wartepflicht. Begrenzung auf drei Stimmen, sichere asynchrone Guards und abbrechbare Folgeereignisse.

Native statische WAV-Quellen und Browser-PCM verwenden denselben Generator. Separates Klangatelier mit 14 Einzelbuttons und zusammenhaengender Faehigkeits-Hoerprobe. Keine neuen Aufnahme-/Hintergrundrechte.

Markdown-Paket fuer GDD, Architektur, Audio, Build, QA, Monetarisierung, Datenschutzinventar, Store-Texte, Review und Entwickler-Uebergabe. App-Version/Build auf 0.4.0/4 vorbereitet. Kanonisches Icon und bestehende Weltengrafiken unveraendert.

Keine neue Spielregel fuer Spezialkombinationen, keine Save-Migration, keine echte Zahlung, keine Werbeintegration, kein Store-Release.
