# Wunderkapseln Alpha 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Execute inline in the isolated local feature branch; no remote writes.

**Goal:** Preserve player progress and all life-pack value, then improve goal-aware hints and measure the campaign without future-refill knowledge.
**Architecture:** Pure profile/storage/strategy modules shared by native and preview clients; retryable hydration gates all persistence. Additive save migration preserves the existing version-1 envelope.
**Tech Stack:** Node 22 ES modules, Expo 55 / React Native, SVG, Playwright.
**Spec:** docs/superpowers/specs/2026-09-14-alpha-0.3.0.md

## Global Constraints
No artwork or canonical icon changes. No WebView, real payments, forced ads, signing material or remote writes. Retain old saves. Native syntax checks and browser QA are not native builds.
