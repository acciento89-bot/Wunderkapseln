# Alpha 0.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task. Check each result before claiming completion.

**Goal:** Add distinct, synchronized ability effects and deliver actionable Markdown release preparation.
**Architecture:** Shared pure sound planning and bounded voice pool; deterministic PCM synthesized into native WAVs and browser buffers. Controller controls event timing; audio cannot modify game state.
**Tech Stack:** Node 22, ESM, React Native/Expo SDK 55, expo-audio, Web Audio, node:test, Playwright.
**Spec:** docs/superpowers/specs/2026-09-14-audio-release-prep.md

## Global constraints

Native iOS and Android; no WebView. 480 existing level recipes; no claim of human balancing. Five hearts, 1500-second regeneration, active-play-only protection. Keep existing icon/splash and art unchanged. No actual payments, ads, credentials, store submission or merge.
