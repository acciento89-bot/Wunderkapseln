# Wunderkapseln Alpha 0.2.0 Implementation Plan

> For agentic workers: use superpowers:executing-plans. Each unit follows a failing regression test, implementation, full retest and local review.

**Goal:** Extend the approved playable alpha with distinct worlds, restoration feedback, original audio and reliable lifecycle handling.
**Architecture:** Keep pure game/profile rules independent from clients. Add restoration and audio-event policies as shared modules; expose client lifecycle changes through GameController. Layer themed SVG landmarks into the existing dome renderer.
**Tech Stack:** Node 22, ECMAScript modules, Expo SDK 55/React Native, SVG, Web Audio/HTML Audio preview, Expo Audio native playback.
**Spec:** docs/superpowers/specs/2026-09-14-alpha-0.2.0.md

## Global Constraints
No WebView, payment simulation, signing data, forced ads, network analytics, or remote write retry. Keep version-1 saves compatible. Native build requires real successful output; a JSX syntax check is not a build.
