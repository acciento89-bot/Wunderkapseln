# Wunderkapseln: approved miniature-world adventure

## Product
Native iOS and Android match-3, German/English, offline campaign, tactile living miniature worlds under glass. 480 campaign definitions across 12 worlds. No subscriptions, compulsory ads or paywalled levels. User approved the concept and implementation in this conversation.

## This implementation
Build a complete playable alpha loop: world selection, level selection, swap/match/cascade gameplay, rockets/bombs/prisms, goals, earned Wonder Move, result/next-level flow, restoration progress, offline saves, lives and active-play timed benefits. Use React Native + Expo SDK 55, native SVG artwork and shared pure JavaScript rules. No WebView. A dependency-free browser harness uses the exact same rules and artwork to exercise the game in this environment; it is not the native app.

## Invariants
- Only orthogonal adjacent swaps that create a match, or activate a special, spend a move.
- Initially no matches and at least one legal move. Dead boards reshuffle without spending a move.
- Four in a line creates a directional rocket; five creates a prism; intersecting lines create a bomb.
- Goals are explicit colored collections and/or clearing frost. All overlays are reachable.
- 5 lives maximum; regeneration every 1500 seconds. Win costs no life. Failed or explicitly abandoned level costs one unless protected. Reopening restores an unfinished attempt instead of resetting it.
- Unlimited-life time only decreases while a level is foregrounded, unpaused and accepting player input. Never in menus, background, ad, result or pause.
- Timed packs sit in inventory until explicit activation. No client grant on shop button press. No real-money purchase buttons until real store verification is connected.
- Progress is sequential. Replay cannot unlock skipped levels or duplicate first-win rewards.
- Versioned save, validation, backup recovery and serialized asynchronous writes. No secret keys in the repository.
- DE for a German device language; EN otherwise, with manual override. Shapes supplement all gem colors. Reduced-motion and haptics switches. Minimum 44-point primary touch targets; square boards on tablets.

## Scope boundaries and release gates
480 definitions are deterministic designed-pattern variations, NOT 480 human-playtested handcrafted levels. First balancing pass is automated; independent device/UX playtests are still required. Paid products and voluntary rewarded ads remain unavailable until native purchase/receipt verification and rewarded-completion integrations exist. No fabricated purchase success, client-only receipt security, real prices, account creation, telemetry, or ads in this alpha. Signing, store setup and iOS/Android device validation are separate release gates. No store upload is authorized by this commit.

## Architecture
core/levels.mjs defines campaign content. core/game.mjs owns rules and reproducible random states. core/profile.mjs owns lives, entitlements and progress. core/session.mjs orchestrates attempts. core/storage.mjs validates and persists snapshots. ui/art.mjs draws shared resolution-independent original artwork; ui/strings.mjs owns all UI copy. App.js is a native interface, web/ is the QA harness. Tests use Node built-ins and need no network.
