# Alpha 0.4.0 - ability audio and preparation

The owner approved continuing the miniature-world game and explicitly requested sounds for big abilities plus comprehensive Markdown preparation.

## Scope

Extend the existing offline sound system, not the game rules. Preserve the canonical icon, artwork, levels, saves, native React Native clients, and fair lives/time system. Keep real payments, ads, and publishing disabled.

Add distinct rocket, bomb, prism, multi-special, wind, tide, bloom, charge-ready and restoration effects. Play effects at the actual burst frame and the outcome after resolution; reduced motion compresses the sound sequence without delaying the game. At most three voices; old asynchronous starts and delayed cues must never resume after pause/background/mute/navigation/disposal. All PCM is original deterministic local synthesis and bundled for native use.

Prepare developer handoff, architecture, game design, audio contract, QA, store-copy drafts, review notes, monetization and privacy/data inventory documents. Clearly distinguish implemented features, proposed products and release blockers. No fake receipts, store availability, native builds, or legal completeness claims.

## Acceptance

Behavioral tests for special detection, timing, lifecycle cancellation, polyphony, source/asset parity and WAV safety. Re-run existing tests and browser regression suites. Produce versioned source ZIP, standalone preview, sound audition page and Markdown package. Native build and external write results are reported separately from local tests.
