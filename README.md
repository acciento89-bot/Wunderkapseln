# Wunderkapseln

A playful, offline-first match-3 adventure for iOS and Android by Kamilunavo.

## Approved game direction

Living miniature worlds under glass domes. Campaign target: 480 levels across 12 worlds, earned Wonder Moves and visible restoration. German and English. Five lives with 25-minute regeneration; optional active-play unlimited-life time. No subscriptions or forced advertising.

Development takes place on feature branches. Store releases require separate signing, purchase integration and device validation. No credentials or signing material belong in this public repository.
